# KitchenKeys – Cloud Kitchen Management System

## About
KitchenKeys is a Cloud Kitchen Management System built using Node.js, Express.js, and SQLite.

## Technologies Used
- Node.js
- Express.js
- SQLite
- JavaScript
- REST APIs

## Features
- Manage chefs
- Manage kitchen stations
- Manage bookings
- Store data using SQLite

## Project Structure
- `server.js` – Main server file
- `database.js` – Database connection
- `database/` – Database folder
- `routes/routes/` – API route files

## Installation and Setup

1. Clone this repository.
2. Install dependencies:

```bash
npm install
```

3. Start the server:

```bash
node server.js
```
